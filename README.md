# Rock Paper Scissors Game Using Data Structures in C

## Project Overview

This project is a console-based Rock-Paper-Scissors game developed using the C programming language. The player competes against the computer, which generates a random move. The program determines the winner and maintains the game score.

The main purpose of this project is to demonstrate the practical implementation of fundamental data structures in a simple and interactive application.

## Features

- New Game
- Random computer move
- Match History
- Undo Last Round
- Show Computer Move Queue
- Score Board
- Menu-driven interface

## Data Structures Used

| Data Structure | Purpose |
|---|---|
| Array | Stores the result of each round |
| Stack | Implements the Undo Last Round feature |
| Queue | Stores computer moves in order |
| Linked List | Stores complete match history |

## Game Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Same moves result in a Draw
